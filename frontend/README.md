# Smart Resume Screening System

## Technologies
- React.js
- Flask
- PostgreSQL
- Scikit-learn
- TF-IDF
- Cosine Similarity

## Features
- HR Registration & Login
- Job Management
- Resume Upload
- AI Resume Screening
- Applicant Management
- Match Score Calculation
- Skills Matching
- PostgreSQL Database

## How to Run

### Backend
pip install -r requirements.txt
python app.py

### Frontend
npm install
npm start
